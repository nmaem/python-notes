# Вложенные списки
## Что это

Вложенный список - это список, элементами которого являются другие списки.

## Создание

Три способа создать список из `n` подсписков по `m` нулей:

### Через append

```python
result = []
for _ in range(n):
    result.append([0] * m)
```

### Через замену

```python
result = [0] * n
for i in range(n):
    result[i] = [0] * m
```

### через comprehension

```python
result = [[0] * m for _ in range(n)]
```

## Ловушка

### Код-ловушка

```python
result = [[0] * m] * n
```
При изменении одного подсписка меняет все:

```python
result = [[0] * 3] * 2
result[0][0] = 5
print(result) # [[5, 0, 0], [5, 0, 0]] — изменились ОБА
```

### Почему так? 

`* n` дублирует ссылку, а не создает новые списки. Все подсписки в данном случае - один объект.

Важно: `[0] * m` - безопасно (числа неизменяемы). Но `[[0] * m] * n` - опасно, потому что список ИЗМЕНЯЕМ.

Проверка: 
`print(result[0] is result[1])   # True — один и тот же объект`

### Как правильно

`result = [[0] * m for _ in range(n)]`

Проверка:

```python
result[0] is result[1] # False. Подсписки - разные объекты.
```
## Чтение из ввода

Шаблон, который повторяется в задачах: 

```python
n = int(input())
result = []
for _ in range(n):
    result.append([int(i) for i in input().split()])
```
**Разбор:**

`n` - сколько строк.

Внешний цикл - n раз.

`input().split()` - строка -> список строк.

`[int(i) for i in ...]` - преобразование в числа.

`.append(...)` - добавить в подсписок.

### Пример

Ввод:

```
3
1 2 3 
4 5 
6 7 8 9
```
Результат: `[[1, 2, 3], [4, 5], [6, 7, 8, 9]]`.

**Вариация: если числа не нужны, а символы:**

`result.append(input().split()) # без int()`

### Что важно упомянуть

`append`, не `extend` - чтобы получился вложенный список.

`int()` нужен, если работает с числами.

Без `int()` если работает со строками.

## Перебор

Есть два способа перебора - по индексам и по элементам.

### По элементам

```python
for row in my_list:
    for elem in row:
        print(elem, end=' ')
    print()
```

Плюсы: коротко, читаемо.

Когда: когда не нужно знать индексы - просто обработать элементы.

### По индексам

```python
for i in range(len(my_list)):
    for j in range(len(my_list[1])):
        print(my_list[i][j], end=' ')
    print()
```
Плюсы: можно изменять элементы, обращаться к соседям, менять порядок.

Когда: когда нужны индексы - например, изменить `my_list[i][j]` или сравнить с `my_list[i][j+1]`. 

### Что выбрать

Если индексы не нужны - **по элементам**. Проще и короче.

Если нужны - **по индексам**.

### Что важно упомянуть

**1. `print(elem, end=' ')`** — вывод **в строку** через **пробел**.

**2. `print()`** в конце **внешнего** цикла — **перевод** строки **после** каждого подсписка.

**3. Изменение** элементов — **только** через **индексы**:

```python
my_list[i][j] = 0    # так можно
```

### Бонус - `sum(row)`

Короткий способ суммы:

```python
total = 0
for row in my_list:
    total += sum(row)
```
